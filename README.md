# 🌌 Space — GitHub Profile Animation

Animated space artwork for Abhay9073's GitHub profile.

## ✨ Includes
- Twinkling stars
- Moving nebula clouds
- Orbiting planets
- Animated sci-fi eye
- Shooting stars
- Pulsing space lights

The profile README uses the SVG as the visual foundation for the cosmic theme.

> GitHub profile READMEs do not permit custom CSS that can pin an animation behind every GitHub UI element. The animation therefore lives inside the README rather than changing GitHub's actual page background.
